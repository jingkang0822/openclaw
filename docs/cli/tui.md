# `clawx tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/web/tui)

## Examples

```bash
clawx tui
clawx tui --url ws://127.0.0.1:19789 --token <token>
clawx tui --session main --deliver
```
