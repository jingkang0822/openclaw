# `clawx setup`

Initialize `~/.clawx/clawx.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
clawx setup
clawx setup --workspace ~/.clawx/workspace
```

To run the wizard via setup:

```bash
clawx setup --wizard
```
